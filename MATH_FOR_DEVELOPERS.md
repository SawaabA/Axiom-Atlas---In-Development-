# Math For Developers

## Graph

Plain language: a graph is a set of things and the connections between them.

In Axiom Atlas: software, papers, and communities are nodes; relationships such as `USES_SOFTWARE` are edges.

## Community Detection

Plain language: community detection groups nodes that are more tightly connected to each other than to the rest of the graph.

In Axiom Atlas: it helps label research software ecosystems such as computational algebra or scientific computing.

## Personalized PageRank

Plain language: Personalized PageRank starts a random walk from things a user already cares about and measures what nearby nodes become important.

In Axiom Atlas: it becomes a recommendation baseline for related software and papers.

## Precision and Recall

Plain language: precision measures how many recommendations are relevant; recall measures how many relevant items we found at all.

In Axiom Atlas: both are needed because a system can be precise but miss too much, or broad but noisy.
