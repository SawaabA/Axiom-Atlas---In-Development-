# API

## Health

- `GET /health`

## Summary

- `GET /v1/summary`

## Search

- `GET /v1/search?q=<query>&entity_type=<optional>`

## Software

- `GET /v1/software`
- `GET /v1/software/{software_id}`
- `GET /v1/software/{software_id}/recommendations`

## Communities

- `GET /v1/communities`
- `GET /v1/communities/{community_id}`

## Graph

- `GET /v1/graph/neighborhood/{node_id}?limit=12`
