# UX Specification

## Experience Goals

- calm, scholarly, and precise
- graph exploration that supports actual research decisions
- high information density without visual clutter
- beginner-friendly layering

## Current Implemented Screens

- homepage with graph preview
- discovery dashboard
- atlas page
- software detail page
- community detail page
- workspace information architecture stub

## Visual System

- dark-first palette with cyan, amber, and violet semantic accents
- expressive sans, restrained serif, and monospace identifiers
- persistent navigation rail and workspace shell

## Accessibility Direction

- every graph workflow requires a non-3D equivalent
- high contrast and readable text sizes
- progressive disclosure of technical details
